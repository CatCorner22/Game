# THRESHOLD

Strategic nuclear-war simulation. Avoid war. If war begins — win.

Turn-based brinkmanship with a 3D globe, a phosphor radar, and a Black Book modeled on the nuclear football (Military Aide briefcase + biscuit). One event a month. One decision.

## Play

- **Blue** — good intent. Prevent war. If it starts, keep a country.
- **Red** — bad intent. Coerce, split, dominate. A spasm war is still a loss.

Seats: United States, Russia, USSR (restorationist C2), China, France, United Kingdom, India, Pakistan, Israel, North Korea, Cuba, transnational cartel, terror network.

Optional **Terminator** mode: a rogue model on the keys.

## Stack

TanStack Start, React, Three.js, Zustand, Tailwind. Local save. No account required.

```bash
npm install
npm run dev
```

## Notes

Arsenals follow FAS / SIPRI-class public estimates (acknowledged, reported, suspected, unacknowledged). The football, biscuit, two-man rule, hotlines, SBIRS/BMEWS, nuclear winter, and human refusal/panic are first-class systems.
